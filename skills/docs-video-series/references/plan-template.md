## Production order and workflow

- **Drawing:** bands left to right (Engine work → Wave 1 (accent, "next") → Wave 2 → Wave 3), each listing its videos, with gate diamonds between them and the gate criteria underneath. No dates unless given.
- **Per video:**
  1. Scripting: write the full sheet.
  2. Build `scenes.js` and render the contact sheet.
  3. Review: contact sheet and 720p preview to the PIC.
  4. Render 1080p (4K on request), then Done.
  5. Cut its short.
- **Series conventions:** the same sample world, caption numbers that follow the docs' sections, and an end card pointing to the product site. Note simplifications in the brief.
