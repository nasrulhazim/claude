## UI/UX Work

**Any UI/UX work starts with the `ui-ux-sop` skill.** New pages, redesigns, landing pages,
dashboards, components, motion, design systems and UI reviews — load `ui-ux-sop` (via the
Skill tool) *before* building, in every project. It classifies the surface, routes it to at
most three design skills, and settles conflicts between them. This applies to delegated work
too: a subagent doing UI must be told, in its brief, to load `ui-ux-sop` first.
Project conventions (component library, dark mode, responsive rules) still apply on top.
